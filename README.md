## 🌟 Featured Product — [ConnectXeo](https://connectxeo.com)

> **AI Agents for Shopify. Free to Build. Live in 10 Minutes.**

A production-grade **multi-agent AI platform** for Shopify merchants. Handles orders, refunds, and customer support 24/7 using a coordinator + 7 specialized sub-agents on a **LangGraph runtime**.

```
Coordinator Agent
├── Orders Agent     — order lifecycle, fulfillments, refunds, returns
├── Products Agent   — catalog, variants, SKUs, inventory, collections
├── Analytics Agent  — revenue, sales trends, top products, reports
├── Customers Agent  — profiles, order history, tags, store credit
├── Marketing Agent  — discounts, promo codes, gift cards, campaigns
├── Payments Agent   — payouts, disputes, shipping zones, carriers
└── Storefront Agent — pages, blogs, themes, menus, translations
```
